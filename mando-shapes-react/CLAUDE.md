## Development Commands

### Starting Development
```bash
npm start
```
Runs the app in development mode with legacy OpenSSL provider and host binding to 0.0.0.0. Opens http://localhost:3000.

### Building for Production
```bash
npm run build
```
Creates optimized production build in `build/` folder with legacy OpenSSL provider.

### Running Tests
```bash
npm test
```
Launches Jest test runner in interactive watch mode.

### Tailwind CSS Compilation
```bash
npx tailwindcss -i ./src/index.css -o ./public/output.css --watch
```
Compiles Tailwind CSS and watches for changes. The output goes to `public/output.css`.

### Deployment
```bash
npm run deploy
```
Builds and deploys to GitHub Pages.

## Architecture

### Core Application Structure
- **React SPA** built with Create React App
- **Styling**: Tailwind CSS + Flowbite React components
- **Main Component Hierarchy**:
  - `App` → `Patterns` → `Pattern` → `Chord`
  - Uses Flowbite `Tabs` component for pattern navigation
  - Horizontal scrolling with snap-scroll for chord display

### Key Components
- **App.js**: Main application with snap-scroll layout and header
- **Patterns**: Tab-based navigation wrapper using Flowbite Tabs
- **Pattern**: Individual pattern display with horizontal scroll
- **Chord**: Individual chord shape display with image and name

### Data Structure
Patterns are defined as static data in `App.js`:
```javascript
const PATTERNS = [
  { 
    name: "Pattern Name",
    shapes: [
      { image: "path/to/image", name: "Chord Name" }
    ]
  }
]
```

### Asset Organization
- **Pattern images**: `public/patterns/[pattern-name]/[chord].svg|png`
- **Logos**: `public/logo_*.png`
- **Compiled CSS**: `public/output.css` (generated by Tailwind)

### Styling Approach
- Uses Tailwind utility classes extensively
- Snap-scroll implementation for both vertical (app sections) and horizontal (chord navigation)
- Responsive design with flexbox layouts
- Flowbite theme integration for tabs and components

### Legacy Configuration Notes
- Requires `NODE_OPTIONS=--openssl-legacy-provider` for both dev and build
- Development server configured with `DANGEROUSLY_DISABLE_HOST_CHECK=true`
- Tailwind config includes Flowbite plugin and dark mode support
